# 結晶生成與最佳化 V0.55

更新時間：2026/10/05 16:30（台灣時間）

## 使用方式

1. 開啟 `index.html`，設定等級、武器與戒指；如有罕見潛能，可在手動套用區填入各項加成總和。
2. 切換至「傳說結晶生成」，預設48顆，可選擇40～75顆與最多三排指定詞條；每排指定詞條會分配到不同結晶。
3. 勾選1～24顆，按「儲存勾選並前往最佳化」。
4. 第一頁會自動載入勾選結晶，不足24顆的欄位留空；按「進行計算」選出最多12顆。

生成頁會自動保存整批結晶、生成數量、三排指定詞條及勾選狀態，切換頁面或重新整理後會恢復；只有按「隨機生成」才會換一批結晶。勾選數量右側的目前爆擊機率以傳說戒指+4的30%為基準，加上已勾選結晶的爆率，超過100%時另外顯示有效100%。

按「原始評分」欄位可循環切換：高分到低分、低分到高分、恢復原始編號順序。排序只改變顯示順序，結晶編號、勾選狀態及跨頁保存內容不變。

第一頁的裝備與罕見潛能設定會保留。罕見潛能可手動輸入魔力、魔攻%、熟練度、爆擊機率、爆擊傷害、最大HP、最大HP%及冷卻時間減免；計算時先套用到基準裝備，再選出最佳結晶。最大HP與最大HP%只列入總加成顯示，不影響目前的傷害轉換公式。原有儲存／載入、JSON匯出／匯入也可使用。「載入生成結晶」可再次載入最後一次傳送的勾選內容。兩頁需在同一網站、同一瀏覽器中開啟，才能共用儲存資料。

## 詞條範圍

| 詞條 | 範圍 | 間隔 |
|---|---|---|
| 魔力 | 200～400 | 10 |
| 魔攻% | 3～5% | 1% |
| 爆擊機率 | 14～16% | 1% |
| 爆擊傷害 | 10～14% | 1% |
| 冷卻時間減免 | 固定2秒 | — |
| 熟練度 | 7～11% | 1% |
| 最大HP | 250～500 | 10 |
| 最大HP% | 5～9% | 1% |

舊資料的1秒冷卻詞條會轉為2秒；其餘不符合範圍的資料會顯示錯誤，不會直接改值。V0.55使用新的生成頁保存區，因此首次開啟會依新HP範圍生成一批結晶，不會覆寫V0.54的整批保存內容。各詞條的生成機率與原檔相同。生成頁原始評分的爆擊傷害效益以100%爆率計算，其倍率為（193＋結晶爆傷）／193；爆率詞條本身維持原評分算法。原始評分仍為單顆戰力提升百分比減5，與實際最佳化結果分開。首次使用預設48顆；已有V0.55保存內容時會沿用保存的數量與結晶，按「隨機生成」才套用新的指定分配規則。計算公式、冷卻轉換倍率、等差減傷及106萬／140萬判定均沿用原檔。

最大HP與最大HP%的上下限參考KMS官方機率公開頁及依該頁整理的資料表；最大HP在本版本依需求以10為生成間隔：

## 上傳到 GitHub Pages

1. 解壓縮ZIP，把 `index.html`、`generator.html`、`.nojekyll`、`README.md` 放到儲存庫最外層。不要上傳ZIP本身，也不要把整個資料夾再套一層。
2. 在該儲存庫開啟 **Settings → Pages**。
3. **Source** 選 **Deploy from a branch**，分支選 **main**，資料夾選 **/(root)**，按 **Save**。若儲存庫使用其他分支名稱，選實際存放檔案的分支。
4. 等GitHub完成發布，再開啟Pages顯示的網站網址。

純HTML，不需要安裝套件或執行建置。每個HTML也可單獨開啟；本機檔案網址下的跨頁儲存取決於瀏覽器，GitHub Pages上則使用同一網站的儲存空間。
